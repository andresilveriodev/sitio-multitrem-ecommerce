# 🌿 Sítio Multitrem - E-commerce
## Guia Completo de Desenvolvimento em Etapas

### Sobre o Projeto
E-commerce single-page para o Sítio Multitrem (Abadiânia-GO) que vende hortaliças frescas e ovos caipiras.

### Stack Tecnológica
- **Frontend:** Next.js 14, React, Tailwind CSS
- **Backend:** Node.js, NestJS (microserviços)
- **Banco de Dados:** PostgreSQL
- **Cache/Filas:** Redis
- **Autenticação:** Keycloak
- **WhatsApp:** Evolution API
- **Pagamentos:** Mercado Pago (Pix, Boleto, Cartão)
- **IA:** OpenAI GPT-4 ou Anthropic Claude

### Estrutura de Pastas Final
```
sitio-multitrem/
├── frontend/                    # Next.js 14
├── services/
│   ├── gateway/                 # API Gateway
│   ├── product-service/         # Catálogo
│   ├── cart-service/            # Carrinho
│   ├── order-service/           # Pedidos
│   ├── payment-service/         # Mercado Pago
│   ├── auth-service/            # Keycloak
│   ├── whatsapp-service/        # Evolution API
│   └── ai-service/              # Assistente IA
├── shared/                      # Tipos compartilhados
└── README.md
```
